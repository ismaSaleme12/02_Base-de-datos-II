## 4. Lectura de auditoría (quién/qué/cuándo/desde dónde)

- Quién: postgres (sesión válida) vs usuario_inexistente (FATAL).
- Qué: SELECT de control (sólo visible con log_statement=all), INSERT y UPDATE
  (visibles ya con 'mod'), llamada a fn_autenticar, FATAL de rol inexistente.
- Cuándo: timestamps con ms; desde dónde: [::1]:puerto + app psql.
- Fuera de alcance nativo: valores OLD/NEW por fila, filas afectadas, parámetros
  de prepared statements y usuario de aplicación tras pooler (todo llega como
  app_web). Para eso, pgaudit (nociones).
